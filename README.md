# GenZ

## Description
The Gen Z Quiz App is an Android application designed to test users’ knowledge of modern Generation Z culture, trends, and digital behaviors.

The app presents fun and interactive questions related to social media, slang, memes, and lifestyle habits of Gen Z. It also provides instant feedback and explanations to make the experience both educational and entertaining.


## Features
- Displays Gen Z-related quiz questions
- Sequential question navigation
- True/False answer buttons
- Instant feedback after each answer
- Explanations for correct and incorrect answers
- Final score display
- Performance evaluation (e.g., Good, Excellent, Needs Improvement)
- Restart quiz option
- Exit button

## Built With
- Kotlin
- Android Studio
- XML layoutds

## How It Works
The user starts the quiz from the main screen
Questions are displayed one at a time
The user selects an answer (True/False)
The app immediately shows:
Whether the answer is correct or incorrect
A short explanation
After completing all questions:
A results screen appears
Final score and feedback are displayed

## Purpose

This app was created to:

- Entertain users with relatable Gen Z content
- Test and improve knowledge of modern trends
- Demonstrate Android development skills
- Practice UI design and user interaction
